# Altar Of Pawful Memories

ROL: Eres un diseñador UX/UI y desarrollador web senior frontend con experiencia en desarrollo en páginas creativas
TAREA: Crea una landing page para hacer un altar digital para mis mascotas, las cuales son un perrito llamado Max, un gato bicolor llamado Felix y un gato gris llamado Anís. CONTEXTO:
Las características de la landing page son: -Paleta de colores tradicional:morado, naranja, flores de sempasuchil. -que sea interactiva al momento de pasar el cursor por algun detalle se agrande -pétalos de cempasúchil cayendo -que inicie a enseñar la web al apretar la nariz de un perro como botón. -La foto de mi perrito (yo te la voy a proporcionar). -un arco de flores de cempasúchil -Guirnalda de papel picado animada en el encabezado. -veladoras con la foto de las mascotas -Que el cursor sea en forma de patita o huellita
